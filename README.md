### Java Version: 21

### Steps to Compile and Run the Application:

1. **Compile the Program:**
   - Open the terminal and navigate to the folder where `VocabularyTool.java` is saved
   - Run the following command to compile the Java program

     ```bash
     javac VocabularyTool.java
     ```

2. **Run the Program:**
   - After successful compilation, run the program using this command

     ```bash
     java VocabularyTool
     ```
